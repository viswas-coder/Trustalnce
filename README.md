# Trustlance 🚀

Trustlance is a modern, secure, two-sided freelance marketplace designed to connect clients with top-tier freelancers. It features a seamless user experience, dedicated role-based dashboards, and a UI built around trust and secure escrow payments.

## ✨ Key Features

* **Role-Based Onboarding:** Seamless registration flow directing users to dedicated Client or Freelancer experiences.
* **Dual Dashboards:** * *Client Dashboard:* Track active projects, total spend, and manage freelance talent.
    * *Freelancer Dashboard:* Monitor active applications, available projects, and earnings.
* **Smart Project Discovery:** A highly interactive project search page featuring real-time filtering, keyword matching, and a "slide-in" quick preview panel to browse jobs without leaving the page.
* **Comprehensive Project Creation:** A multi-step form for clients to post projects, define strict budget parameters (Fixed vs. Milestone), and set escrow protection requirements.
* **Premium UI/UX:** Built with a modern dark theme, warm accent colors, smooth animations, and responsive components.

## 🛠️ Tech Stack

* **Frontend Framework:** React + TypeScript
* **Styling:** Tailwind CSS
* **UI Components:** shadcn/ui & Radix UI
* **Icons:** Lucide React
* **Routing:** Wouter

## 🚀 Getting Started

To run this project locally, clone the repository and install the dependencies:

```bash
# Clone the repository
git clone [https://github.com/your-username/trustlance.git](https://github.com/your-username/trustlance.git)

# Navigate into the project directory
cd trustlance

# Install dependencies
npm install

# Start the development server
npm run dev
